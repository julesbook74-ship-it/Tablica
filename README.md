# TABLICA — prototyp

To jest działający prototyp aplikacji do wspólnych notatek.

## Uruchomienie
Otwórz `index.html` w przeglądarce.

## Co działa
- tworzenie i przełączanie tablic,
- dodawanie, edycja i usuwanie notatek,
- kolorowe notatki,
- wyszukiwanie,
- automatyczny zapis w przeglądarce,
- demonstracyjne zaproszenie drugiej osoby,
- synchronizacja między kartami tej samej przeglądarki przez BroadcastChannel.

## Kolejny etap
Aby dwie osoby mogły korzystać z jednej tablicy przez internet, trzeba podłączyć backend z bazą danych i autoryzacją (np. Supabase/Firebase). Interfejs jest już przygotowany pod taki etap.
